# Password Strength Checker

A small, client-side password strength checker built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools, server, database or dependencies are required.

## Privacy and limitations
- Password checks run in the browser; this project does not transmit or store the entered value.
- Use sample passwords for demonstrations, not a real password you currently use.
- The score is a simple educational heuristic, not a cryptographic strength estimate. It does not check breached-password databases or guarantee account security.
